First release of `@mmd-toolkit/textmate-grammar`, a TextMate grammar for Mermaid
text written from version 0.1.0 of the specification. It colors every unit of
the 32 diagram types: their headers and keywords, the names of elements, labels,
types, shapes, styles, comments and directives. It ships the grammar as
`mermaid.tmLanguage.json`, for VS Code and other TextMate hosts, and as a
language registration for Shiki.
