# Building the C4 Db from the tree

Japanese version: [c4.ja.md](./c4.ja.md)

`src/db-from-tree/c4.ts` implements these steps for
[ast/c4.md](../../../spec/docs/ast/c4.md), following
[db-summaries.md, c4](../db-summaries.md#c4). `tests/db-from-tree-c4.test.ts`
supplies the trees by hand and compares their summaries with the cited fixtures'
recorded Dbs, including after a JSON round trip with tokens inaccessible and
source reads confined to value-node ranges.
