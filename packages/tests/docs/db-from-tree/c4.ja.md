# 木から C4 の Db を組み立てる

英語版: [c4.md](./c4.md)

`src/db-from-tree/c4.ts` は、
[ast/c4.md](../../../spec/docs/ast/c4.ja.md) の木について、
[db-summaries.md の c4](../db-summaries.ja.md#c4) に従い実装します。
`tests/db-from-tree-c4.test.ts` は木を手作りし、
引用したフィクスチャの記録済み Db と比較します。
JSON の往復後も、トークンを参照できず、
ソースの参照を値ノードの範囲内に限った状態で比較します。

## 木から要約を組み立てる

1. **テキスト。** リテラルや文字列の範囲を、
   書かれた値から無視されたセミコロンを識別して変換します。
   ディレクティブ、コメント領域、文字列の区切りを除き、
   CR と CRLF を LF、HTML 属性の引用符を一重引用符、
   実体参照をプレースホルダーに変換します。
   引用されたものも含め、引数と名前付き属性のキーと値の外側の空白を除きます。
