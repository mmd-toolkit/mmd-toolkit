## 0.1.0

### Minor Changes

- [#7](https://github.com/mmd-toolkit/mmd-toolkit/pull/7) [`6d35b63`](https://github.com/mmd-toolkit/mmd-toolkit/commit/6d35b6396f74b1ab4c1022a803cbaf865ba24bb4) Thanks [@ota-meshi](https://github.com/ota-meshi)! - First release of `@mmd-toolkit/textmate-grammar`, a TextMate grammar for Mermaid
  text written from version 0.1.0 of the specification. It colors the forms people
  write in the 32 diagram types: their headers and keywords, the names of
  elements, labels, types, shapes, styles, comments and directives. It ships the
  grammar as `mermaid.tmLanguage.json`, for VS Code and other TextMate hosts, and
  as a language registration for Shiki.
