# C4 nodes

Japanese version: [c4.ja.md](./c4.ja.md)

This document defines the tree for the diagram type `c4`. The shared parts are
in [ast.md](../ast.md), and syntax and acceptance are in
[diagrams/c4.md](../diagrams/c4.md). How mermaid.js reads the values into its Db
is in the [tests package summary](../../../tests/docs/db-summaries.md#c4).

Values keep the written text of [Nodes](../ast.md#nodes), including original
line terminators, and leave out directives, common comment regions, and selected
ignored semicolons. [fixture: c4/lex-bare-crlf-directive] [fixture:

### C4NamedAttribute

| Field   | Type              | Meaning                                                          |
| ------- | ----------------- | ---------------------------------------------------------------- |
| `key`   | C4Literal or null | The key after `$`, without exterior whitespace; null when empty. |
| `value` | StringLiteral     | The nonempty quoted value after `=`.                             |

Child fields: `key`, `value`, in that order. [fixture:
c4/db-named-key-whitespace] [fixture: c4/lex-named-empty-key]

The key is a C4Literal and may contain whitespace and line terminators, as in
`$first` followed by a line `second="V"`; `$="x"` has a null key. [fixture:
c4/db-named-key-whitespace] [fixture: c4/lex-named-key-multiline] [fixture:
c4/lex-named-key-comma-close] [fixture: c4/lex-named-empty-key]

its quotes in `raw`. [fixture: c4/lex-named-empty-key] [fixture:
c4/lex-directive-named-equals-quote]

An empty named value is rejected, while a whitespace-only named string keeps its
whitespace and is not null. [fixture: c4/gram-named-empty-value] [fixture:
