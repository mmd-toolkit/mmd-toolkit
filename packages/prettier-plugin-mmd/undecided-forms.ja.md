# 印字する形の残りの作業

整形ツールは、下の形を書かれたまま印字している。
しかし、[印字する形の決め方](./docs/printed-form.ja.md) のどの決まりも、
その形を与えておらず、残す理由も記録されていない。
対象にする mermaid.js の版で、別の形が Db や図を変えることも、拒否されることも、
走らせて示されていない。
利用者も決めていない。
これらは決まりではなく、残っている作業である。

それぞれの形は、次のように決める。
別の形を、対象にする版で走らせる。
どの種類の例外も認めない形で Db が変わるか、図が変わるか、拒否されるときは、
その理由を図種の規則に書く。
対象にする版が要るときは、
[対象にする版の mermaid.js のために残す形](./docs/compatibility.ja.md#対象にする版の-mermaidjs-のために残す形)
にも行を足す。
そうでないときは、AGENTS.md の 4 のとおり、より読みやすい形を利用者に提案する。
決まった形はこの一覧から外し、一覧が空になったらこのファイルを消す。

この一覧は、まだ全部ではない。
理由なく書かれたまま残している形を、すべての図種の規則から探している途中である。

| 図種                        | 書かれたまま印字している形                                                            |
| --------------------------- | ------------------------------------------------------------------------------------- |
| flowchart、agentflow        | `accTitle :%%{init: {}}%% x` のコロンの前の空白                                       |
| flowchart、class            | コメントか directive を含む `style` と `classDef` の空白                              |
| すべての図種                | frontmatter の `---` の行の末尾の空白とタブ                                           |
| venn                        | `rgb(1 ,2 ,3)` のような、スタイルの色のコンマの前の空白                               |
| sankey                      | `sankey-BETA` の大文字と小文字                                                        |
| xychart                     | `xychart-BETA` の `-BETA` の大文字と小文字                                            |
| agentflow                   | 引用符に入れない、`[a/b]` のような connector の題                                     |
| gantt                       | `excludes weekends,,2024-01-01` のように、空の項目の前に空白を足さないこと            |
| gantt                       | `excludes` の後の `Weekends` の大文字と小文字                                         |
| 数を 1 つの形で印字する図種 | `007` のように、整数部の頭に 0 がある数                                               |
| eventmodeling               | 枠のキーワードをどちらの綴りで印字するか（`timeframe` か `tf`、`resetframe` か `rf`） |
| railroad                    | 書かれたとおりに付けるか省く EBNF のコンマ                                            |
| sequence                    | `participant"A"` のように、`participant` と引用符の名前の間に空白がないこと           |
| journey                     | `05` のように、頭に 0 がある点数                                                      |

## 版ごとに残す形の表にまだない行

[印字する形の決め方](./docs/printed-form.ja.md#対象にする-mermaidjs-の版) は、
固定した版そのものが拒否するか、違って読むか、違う図に描く形に、
[対象にする版の mermaid.js のために残す形](./docs/compatibility.ja.md#対象にする版の-mermaidjs-のために残す形)
の行を与える。
この決まりより前に、その理由で残した形には、まだ行がない。
それぞれの行は、その図種の規則を探すときに足す。
