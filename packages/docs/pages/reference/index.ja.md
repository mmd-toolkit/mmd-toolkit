# 互換性

mmd-toolkitは、**mermaid.js 12.2.0**を互換性の基準とします。
対応する図の種類は、[図の対応状況](./support.ja.md)を参照してください。

## 保証する性質

- パーサーは、[既知の差異](../../../spec/docs/known-divergences.ja.md)を除き、
  mermaid.jsと同じ図のテキストを受理・拒否し、
  受理したテキストを同じ図として読みます。
- 整形は冪等です。
  整形結果を再び整形しても、同じテキストになります。
  [明記された例外][formatter]を除き、図の意味を保持します。
- リンターは同じパーサーを使い、構文エラーと、
  有効なルールの対象になる書き間違いを報告します。

既知の差異のページでは、受理や読み取りが異なる入力と、
各差異が図の作者に与える影響を説明しています。

## 検証する範囲

互換性の対象は、図のテキストの構文です。
描画・レイアウトと、Mermaidのサイト設定に依存する検証は対象外です。

パーサーは、frontmatterの本文、directiveの引数、
`@{ ... }`のデータブロックをテキストとして保持します。
開始位置と終了位置は認識しますが、中身が正しいYAMLやJSONか、
値の型やノード形状などの名前が正しいかは検証しません。
そのため、このツールが受理する埋め込みデータをMermaidが拒否することがあります。
詳しくは、[埋め込みデータの差異][embedded]を参照してください。
